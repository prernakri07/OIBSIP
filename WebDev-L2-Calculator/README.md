##  Project Overview
This project is a functional and responsive calculator web application developed using HTML5, CSS3, and JavaScript.
The calculator provides basic arithmetic operations through an easy-to-use graphical interface.
It supports addition, subtraction, multiplication, division, operator chaining, clearing the display, and deleting the last entered character.

##  Objective
The objective of this project is to create an interactive calculator that demonstrates the use of:
- HTML5
- CSS3
- JavaScript
- CSS Grid
- JavaScript event listeners
- DOM manipulation
- Arithmetic operations
- Input validation
- Error handling

##  Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)
- CSS Grid
