# Dr. A. P. J. Abdul Kalam — Tribute Page 🇮🇳
## OASIS Infobyte Internship
Track: Web Development & Designing  
Level: Level 2  
Task: Task 2 - Tribute Page

## Project Overview
This project is a visually engaging tribute page dedicated to Dr. A. P. J. Abdul Kalam, one of India's most respected scientists, teachers, and former Presidents.
The webpage presents his life journey, major achievements, contributions to science and technology, and his inspiring connection with students and young people.

##  Objective
The objective of this project is to create a responsive and attractive tribute webpage using HTML5 and CSS3.
The page demonstrates:
- Semantic HTML structure
- CSS styling and layout
- Responsive web design
- Multiple background colours
- Different font styles
- Image integration
- Timeline design
- Styled quotation section

##  Technologies Used
- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- Responsive Media Queries
- Google Fonts

##  Features
###  Subject Introduction
The page introduces Dr. A. P. J. Abdul Kalam with his name, a tagline, and a prominent hero section.

###  Prominent Image
A photograph of Dr. Kalam is included using an image sourced from Wikimedia Commons.

###  Biography
The tribute page contains original, paraphrased content describing his:
- Early life
- Education
- Scientific career
- Contributions to India's space and defence programmes
- Presidency
- Work with students and young people

###  Timeline
Important milestones from his life are presented in a visually structured timeline.
The timeline includes events such as:
- 1931 — Birth
- 1950s — Engineering education
- 1960s — Space programme
- 1980s — Missile development
- 2002 — President of India
- 2015 — Final lecture and passing

###  Quote Section
A dedicated quote section highlights an inspiring message associated with Dr. Kalam.

###  Multiple Backgrounds
Different sections of the webpage use different background colours to create visual separation and improve readability.

###  Multiple Font Styles
The project uses:
- Playfair Display for headings and important quotations
- Poppins for body text and general content

### Responsive Design
The webpage adapts to different screen sizes, including:
- Desktop
- Laptop
- Tablet
- Mobile phones
