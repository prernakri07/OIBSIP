##  Project Overview

The Temperature Converter is an interactive web application that converts temperature values between Celsius, Fahrenheit, and Kelvin.
The website provides a simple and user-friendly interface where users can enter a temperature, select the input unit, and convert the value into the other temperature units.
The project also includes input validation and absolute-zero checking to provide accurate and meaningful results.

##  Objective
The main objective of this project is to build an interactive temperature conversion tool using HTML5, CSS3, and Vanilla JavaScript.

The project demonstrates:
* Form input handling
* Unit selection
* Temperature conversion
* JavaScript calculations
* Input validation
* Error handling
* Responsive UI design

##  Features

###  Temperature Input
Users can enter a numeric temperature value into the input field.

###  Unit Selection
Users can select the input temperature unit from:
* Celsius (°C)
* Fahrenheit (°F)
* Kelvin (K)

###  Multiple Output Units
After conversion, the result displays the temperature in:
* Celsius
* Fahrenheit
* Kelvin

###  Input Validation
The application checks whether the entered value is numeric.
If the input is invalid, a clear and user-friendly error message is displayed.

###  Absolute Zero Validation
The application handles temperatures below absolute zero and displays an appropriate error message.

Examples:
* Celsius below −273.15°C
* Fahrenheit below −459.67°F
* Kelvin below 0 K

###  Convert Button
A dedicated Convert button performs the temperature conversion when clicked.

## Conversion Formulas

### Celsius to Fahrenheit : °F = (°C × 9/5) + 32
### Celsius to Kelvin : K = °C + 273.15
### Fahrenheit to Celsius : °C = (°F − 32) × 5/9
### Fahrenheit to Kelvin : K = (°F − 32) × 5/9 + 273.15
### Kelvin to Celsius : °C = K − 273.15
### Kelvin to Fahrenheit : °F = (K − 273.15) × 9/5 + 32
